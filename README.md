# About
A casino card games website for a Computer Science 3 Advanced class

Made using the Svelte (frontend) & SvelteKit (backend) framework alongside TypeScript (JavaScript but with static types)
ChatGPT was primarily used as a supplement and not a replacement (Deck class is the only exception)

## Running the server
Just type `npm install` then `npm run dev` under the cs3gamesite root folder to start the server and open the localhost in your browser
If you want to run the server and open the website on another computer, use the command `npm run dev -- --host` instead and replace `localhost:port` with `IPv4_address:port`
